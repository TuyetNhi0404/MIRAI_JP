Cài AI Speaking sau khi clone MIRAI JP

Lệnh npm run dev:speaking tự tải/cài Python service, Whisper STT, MeloTTS và llama.cpp. File model GGUF fine-tune phải do người dùng tự tải và chép vào dự án.

1. Cài công cụ nền

Windows

  1. Cài Node.js 18+, Git for Windows, CMake (chọn Add CMake to PATH).
  2. Cài Microsoft C++ Build Tools, chọn workload Desktop development with C++.
  3. Đóng và mở lại PowerShell, kiểm tra: git --version, cmake --version, node --version.

Linux Ubuntu/Debian

sudo apt update
sudo apt install -y git cmake build-essential ffmpeg
node --version

2. Clone và đặt model GGUF

tải model từ link google drive, model là qwen3-1.7b.Q4_K_M.gguf , lưu ý không được đổi tên file model

Windows PowerShell

git clone <URL_REPOSITORY> MIRAI_JP
cd MIRAI_JP -> tải thư viện cho FE/ BE/ bằng lệnh ```npm install```

3. Cấu hình Speaking service

Tạo file services/speaking-practice/.env từ .env.example

Giữ các giá trị local sau trong file .env:

LOCAL_LLM_MODEL_PATH=models/qwen3-1.7b.Q4_K_M.gguf
LOCAL_LLM_URL=http://localhost:8080
MELO_TTS_URL=http://localhost:8001
LLAMA_GPU_LAYERS=0
WHISPER_MODEL_SIZE=medium
SPEAKING_INTERNAL_KEY=mirai-speaking-dev-key
ALLOWED_ORIGINS=http://localhost:5000,http://localhost:5173

Không cần cấu hình WHISPER_BIN hoặc WHISPER_MODEL khi chạy bằng npm. Script tự tạo đường dẫn đúng theo hệ điều hành, ví dụ Windows: C:\Users\<user>\whisper.cpp\build\bin\whisper-cli.exe. Nếu có sẵn các biến này với đường dẫn Linux trong .env, hãy xóa hoặc comment chúng.

4. Chạy

npm run dev:speaking

Lần chạy đầu tải dependency và build C++ nên sẽ lâu. Khi thành công: FastAPI ở port 8000, MeloTTS ở 8001, llama.cpp ở 8080.

5. Kết nối với Backend

Trong BE/.env, kiểm tra:

ENABLE_SPEAKING_PRACTICE=true
SPEAKING_SERVICE_URL=http://127.0.0.1:8000
SPEAKING_INTERNAL_KEY=mirai-speaking-dev-key

SPEAKING_INTERNAL_KEY phải giống giá trị trong services/speaking-practice/.env. Khởi động Backend và Frontend như bình thường.

6. Lỗi thường gặp

  • git/cmake chưa có trong PATH: cài công cụ, mở terminal mới rồi chạy lại.
  • Không nhận model: kiểm tra file là models/mirai-jp.gguf hoặc sửa LOCAL_LLM_MODEL_PATH.
  • Không cần model để test service: thêm GEMINI_API_KEY hoặc OPENROUTER_API_KEY vào .env; hệ thống sẽ dùng cloud fallback.
